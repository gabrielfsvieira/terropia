## Editor canônico
- Leia `WORLD_EDITOR_CURRENT.json` primeiro.
- A versão em `canonicalEditor` é a única runtime oficial.
- Runtimes antigos devem ser removidos antes de qualquer ZIP de entrega.
- O editor mais recente sempre prevalece.
