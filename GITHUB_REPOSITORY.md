## Fluxo oficial
1. Manter todo o conteúdo deste ZIP no mesmo repositório.
2. Testar o jogo pela raiz e editar o mapa em `/editor/`.
3. Exportar o pacote completo do editor quando houver mudanças.
4. Enviar o ZIP completo ao ChatGPT.
5. O ChatGPT aplica as mudanças, incrementa a versão e devolve um único `VNNNNN.zip`.
6. Substituir o conteúdo do repositório pela nova release.

O armazenamento local do editor é por navegador/dispositivo. O ZIP/repositório continua sendo a fonte autoritativa entre dispositivos.
