# Regra obrigatória — World Map

A partir da v00163, a planilha **Mapa_Mundo_COMMON_RPG_vXX.xlsx** faz parte obrigatória do pacote ZIP.

Sempre que uma nova versão alterar regiões, tiers, telas, códigos AT, conexões, nomes de telas ou geometria do mapa mundial:
1. atualizar os dados do jogo;
2. atualizar a planilha de World Map na mesma versão;
3. manter a planilha dentro do ZIP final;
4. validar contagem de telas, códigos e tiers antes de empacotar.

Não publicar uma versão de World Map sem a planilha sincronizada.
